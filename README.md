# AquaScape Aquarium

A premium, responsive aquarium shop website built with HTML, CSS, JavaScript, Bootstrap 5, Font Awesome, and Swiper.js.

## Overview

This project is a static multi-page website for an aquarium brand that offers aquarium design, installation, maintenance, and products. It includes:

- Home page with hero banner, stats, featured works, products, reviews, FAQ, and newsletter
- About page with brand story, mission, vision, and values
- Products page showcasing available aquarium supplies
- Works page with project portfolio
- Contact page with enquiry form and business details
- Sticky navigation, smooth scrolling, floating WhatsApp button, and mobile responsive layout

## Project structure

- `index.html` - home page
- `about.html` - about us page
- `products.html` - products catalog page
- `works.html` - portfolio page
- `contact.html` - contact page
- `css/` - stylesheets
- `js/` - JavaScript files
- `assets/` - images, icons, and media assets

## Run locally

Because this is a static website, you can preview it by opening any HTML file directly in a browser.

For a local server, from the project root run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
